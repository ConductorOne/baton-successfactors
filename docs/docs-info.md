## Connector capabilities

1. What resources does the connector sync?
   This connector syncs:
    - Users
    - Groups

2. Can the connector provision any resources? If so, which ones?
   No.

## Connector credentials

1. What credentials or information are needed to set up the connector? (For example, API key, client ID and secret, domain, etc.)
    - For this connector, an OAuth application on the SuccessFactor instance is required.

2. For each item in the list above:

    * How does a user create or look up that credential or info? Please include links to (non-gated) documentation, screenshots (of the UI or of gated docs), or a video of the process.
        1. Log into your SuccessFactors account.
        2. Go to the 'Admin Center'.
        3. Search for the 'API Center' module.
        4. Click on 'OAuth Configuration for OData' option or directly search for 'Manage OAuth2 Client Applications'.
        5. Click on the 'Register Client Application' button.
        6. Enter the "Application Name" you desire, the "Application URL" and provide your X.509 Certificate without the Header or the Footer.
           [DO NOT USE THE CERTIFICATE GENERATED BY SAP SUCCESSFACTORS: The private key generated by the builtin capability is corrupted]
        7. Once everything is ready, click on 'Register'.
        8. Search for the Application you just created on the list and click on 'View'.
        9. Look for the "API Key" field and copy the content. That will be both your "Client ID" and "SAML API Key".

    * What level of access or permissions does the user need in order to create the credentials? (For example, must be a super administrator, must have access to the admin console, etc.)  
      The user should be an admin.
